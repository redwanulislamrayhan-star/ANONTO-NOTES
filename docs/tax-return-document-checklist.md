## ক. মৌলিক পরিচয় ও নিবন্ধন কাগজ

- [ ] **জাতীয় পরিচয়পত্র (NID)** — সামনে ও পেছনে পরিষ্কার কপি
- [ ] **পাসপোর্ট** — তথ্য পৃষ্ঠা + **সব স্ট্যাম্প/ভিসা পৃষ্ঠার কপি** (বিদেশ যাওয়া-আসার হিসাবের জন্য — খুবই জরুরি)
- [ ] **e-TIN সার্টিফিকেট** (বর্তমান + পুরনো, যদি টিন বদলে থাকে)
- [ ] **সর্বশেষ দাখিলকৃত রিটার্নের কপি** (আগের বছরের) + রিটার্ন রিসিট/অ্যাকনলেজমেন্ট (IT-10) + অ্যাসেসমেন্ট নোটিশ (যদি থাকে)
- [ ] NID না থাকলে: **জন্ম সনদ / ড্রাইভিং লাইসেন্স**
- [ ] পাসপোর্ট সাইজ ছবি (২ কপি)
- [ ] যোগাযোগ: মোবাইল, ইমেইল, স্থায়ী + বর্তমান ঠিকানা (ফর্মে লিখে নিন)
- [ ] **রিফান্ড পাওয়ার জন্য ব্যাংক অ্যাকাউন্টের তথ্য** (অ্যাকাউন্ট নম্বর, ব্যাংক, শাখা)

## খ. রেসিডেন্সি নির্ধারণের কাগজ (প্রবাস থেকে ফেরত — সবচেয়ে জরুরি অংশ)

> বাংলাদেশের নিয়ম (Income Tax Act ২০২৩): আয়কর বছরে (জুলাই–জুন) বাংলাদেশে **১৮২ দিন বা তার বেশি** থাকলে রেসিডেন্ট; অথবা বছরে **৯০ দিন + আগের ৪ বছরে মোট ৩৬৫ দিন**। রেসিডেন্ট হলে **বিশ্বব্যাপী আয়** ধার্য হয়। তাই দিনের হিসাব প্রমাণ করা জরুরি।

- [ ] **পাসপোর্টের এন্ট্রি/এক্সিট স্ট্যাম্প** — আয়কর বছরের প্রতিটি যাওয়া-আসার তারিখ (দিন-গণনার টেবিল বানান)
- [ ] **বিদেশি চাকরির নিয়োগপত্র / চুক্তিপত্র** — শুরুর ও সমাপ্তির তারিখসহ
- [ ] **ভিসা / ওয়ার্ক পারমিট / রেসিডেন্স পারমিট / গ্রিন কার্ড** কপি
- [ ] **দেশে ফেরার প্রমাণ** — এয়ার টিকিট / ভিসা স্ট্যাম্প / জয়েনিং লেটার
- [ ] **বর্তমান (বাংলাদেশি) চাকরির নিয়োগপত্র/জয়েনিং লেটার** — থাকলে
- [ ] বিদেশে দাখিল করা **ট্যাক্স রিটার্নের কপি** (যেমন USA: Form 1040, UK: SA100/SA302, মধ্যপ্রাচ্য: পে-ট্যাক্স রিটার্ন) — প্রতি বছর
- [ ] বিদেশি কর কর্তৃপক্ষের **অ্যাসেসমেন্ট/কর পরিশোধের রসিদ** (ফরেন ট্যাক্স ক্রেডিটের জন্য)
- [ ] **ট্রাভেল হিস্ট্রির সংক্ষিপ্ত ছক** — কোন তারিখে কোথায় ছিলেন (করদাতাকে দিয়ে পূরণ করান)

## গ. দেশে অর্জিত আয়ের উৎসভিত্তিক কাগজ

### বেতন (যদি বর্তমানে চাকরি করেন)
- [ ] নিয়োগপত্র / অ্যাপয়েন্টমেন্ট লেটার
- [ ] **বেতন বিবরণী (সব মাসের)** — বুনিয়াদি, বাড়ি ভাড়া, যাতায়াত, মেডিকেল, বোনাস, কমিশন, ওভারটাইম ইত্যাদি
- [ ] ব্যাংক স্টেটমেন্ট — বেতন ক্রেডিটের প্রমাণ
- [ ] **উৎসে কর কর্তনের সনদ (TDS Certificate / Form-4 / পারিশ্রমিক বিবরণী)** — নিয়োগকর্তার কাছ থেকে

### বাড়ি ভাড়া (দেশে সম্পত্তি থাকলে — প্রবাসে থেকেও এটি করযোগ্য!)
- [ ] ভাড়া চুক্তি (সব প্রপার্টি)
- [ ] **হোল্ডিং ট্যাক্স / মিউটেশন রিসিট**
- [ ] ভাড়া জমার ব্যাংক স্টেটমেন্ট / ভাড়াটিয়ার NID কপি
- [ ] বাড়ির ইউটিলিটি বিল (ঠিকানা প্রমাণে)

### ব্যবসা / পেশা (যদি থাকে)
- [ ] ট্রেড লাইসেন্স + নিবন্ধন কাগজ
- [ ] আয়-ব্যয়ের হিসাব / প্রফিট-লস স্টেটমেন্ট
- [ ] ব্যাংক স্টেটমেন্ট (ব্যবসায়িক অ্যাকাউন্ট)
- [ ] VAT / অন্যান্য নিবন্ধন (থাকলে)

### সুদ, সঞ্চয় ও বিনিয়োগ আয়
- [ ] FDR / সঞ্চয়পত্রের সুদের **ব্যাংক সার্টিফিকেট + TDS সার্টিফিকেট**
- [ ] সঞ্চয়পত্র (NSD) সার্টিফিকেটের কপি
- [ ] শেয়ার ডিভিডেন্ড ওয়ারেন্ট / **BO স্টেটমেন্ট**
- [ ] মিউচুয়াল ফান্ড / ICB ইউনিট ফান্ড স্টেটমেন্ট

### মূলধনী আয় (থাকলে)
- [ ] সম্পত্তি বিক্রির দলিল / শেয়ার বিক্রির কন্ট্রাক্ট নোট — লাভের হিসাবের জন্য

## ঘ. বিদেশে অর্জিত আয়ের কাগজ (প্রবাসকালীন — ফরেন ট্যাক্স ক্রেডিটের জন্য)

- [ ] **বিদেশি বেতন স্লিপ (পে-স্লিপ)** — প্রবাসের প্রতিটি মাস
- [ ] বিদেশি **W-2 / Form 16 / পে-ট্যাক্স / সার্ভিস লেটার**
- [ ] বিদেশি চাকরির চুক্তিপত্র ও পুনর্নবীকরণ চিঠি
- [ ] **বিদেশি কর পরিশোধের সনদ** (ফরেন ট্যাক্স পেইড সার্টিফিকেট/ট্যাক্স রিটার্ন) — দেশে ডাবল ট্যাক্স রিলিফ/ক্রেডিট দাবি করতে
- [ ] বিদেশি ব্যাংক অ্যাকাউন্টের **স্টেটমেন্ট (সারা বছরের)** + ব্যালেন্স সার্টিফিকেট
- [ ] বিদেশি পেনশন / রিটায়ারমেন্ট / সিকিউরিটিজ অ্যাকাউন্ট স্টেটমেন্ট
- [ ] বিদেশি সম্পত্তি / বিনিয়োগের কাগজপত্র (থাকলে)
- [ ] **বিদেশ থেকে বাংলাদেশে রেমিট্যান্সের ব্যাংক স্টেটমেন্ট / এনক্যাশমেন্ট সার্টিফিকেট**
- [ ] বিদেশে কর কর্তনের জন্য বাংলাদেশি কর্তৃপক্ষের কাছে **TRC (ট্যাক্স রেসিডেন্সি সার্টিফিকেট) আবেদনের কাগজ** (প্রয়োজনে)

## ঙ. কর রিবেট / ছাড়ের কাগজ (বিনিয়োগ)

- [ ] **জীবন বীমা প্রিমিয়ামের রসিদ** (সব পলিসি)
- [ ] **DPS (ডিপোজিট পেনশন স্কিম) স্টেটমেন্ট**
- [ ] **সঞ্চয়পত্র ক্রয়ের রসিদ/সার্টিফিকেট**
- [ ] **প্রভিডেন্ট ফান্ড বিবরণী** (নিয়োগকর্তার স্টেটমেন্ট)
- [ ] **শেয়ার/মিউচুয়াল ফান্ড/ICB ইউনিট** ক্রয়ের কাগজ + BO স্টেটমেন্ট
- [ ] **বাড়ি নির্মাণ / জমি / ফ্ল্যাট কেনার** রসিদ, দলিল, লোন স্টেটমেন্ট
- [ ] সরকারি সিকিউরিটিজ / বন্ড ক্রয়ের কাগজ
- [ ] **অনুদানের রসিদ** (NBR-অনুমোদিত প্রতিষ্ঠানে) — ছাড় দাবি করলে
- [ ] **যাকাত পরিশোধের রসিদ** (যদি দাবি করেন)

## চ. সম্পদের বিবরণী (রিটার্নের সাথে দেওয়া সম্পদ তালিকার জন্য)

- [ ] **সব ব্যাংক অ্যাকাউন্টের স্টেটমেন্ট + ব্যালেন্স সার্টিফিকেট** — দেশি ও বিদেশি (৩০ জুন তারিখের ব্যালেন্সসহ)
- [ ] FDR / সঞ্চয়পত্র / মিউচুয়াল ফান্ড / শেয়ার (BO) — স্টেটমেন্ট
- [ ] **রিয়েল এস্টেট**: দলিল, মিউটেশন, হোল্ডিং ট্যাক্স রিসিট, বর্তমান বাজার মূল্যায়ন
- [ ] **গাড়ি / মোটরসাইকেল** — রেজিস্ট্রেশন পেপারের কপি
- [ ] **স্বর্ণালংকার** — পরিমাণ ও আনুমানিক মূল্যের তালিকা
- [ ] দোকান/ব্যবসায়িক অংশীদারি/ফিক্সড ডিপোজিটের কাগজ
- [ ] **দায়/লোন**: ব্যাংক লোন স্টেটমেন্ট, ক্রেডিট কার্ড স্টেটমেন্ট, অন্যান্য পাওনা

- [ ] রিটার্ন দাখিলের পর **রিসিট/অ্যাকনলেজমেন্ট কপি** (করদাতাকে দিন)
- [ ] করদাতার সাথে **যোগাযোগের নোট** (অনুমোদিত)

## গুরুত্বপূর্ণ মনে রাখবেন

1. **রেসিডেন্সি = সবকিছু**: দিনের হিসাব ঠিকমতো না হলে রেসিডেন্ট/নন-রেসিডেন্ট ভুল হতে পারে → পুরো ট্যাক্স হিসাব বদলে যাবে। তাই পাসপোর্ট স্ট্যাম্প ও ট্রাভেল হিস্ট্রি **অগ্রাধিকার নিয়ে** সংগ্রহ করুন।
2. **ফরেন ট্যাক্স ক্রেডিট**: বিদেশে দেওয়া করের জন্য দেশে ক্রেডিট দাবির নিয়ম ও **সময়সীমা** আছে (DTAA অনুযায়ী) — বিদেশি কর পরিশোধের সনদপত্র আবশ্যক।
3. **প্রবাসকালেও বাংলাদেশি সম্পত্তির ভাড়া/আয় করযোগ্য** — দেশের বাড়ির ভাড়া ও অন্যান্য দেশি আয় মিস করবেন না।
4. ব্যক্তিগত তথ্য (পাসপোর্ট, NID, ব্যাংক স্টেটমেন্ট) **নিরাপদে রাখুন**, প্রয়োজনের বাইরে শেয়ার করবেন না; করদাতার অনুমতি ছাড়া কোথাও ব্যবহার করবেন না।
5. আইন ও ফরম প্রতি বছর (Finance Act সংশোধনীসহ) বদলায় — দাখিলের আগে **বর্তমান NBR ফরম ও নিয়ম** মিলিয়ে নিন।

*প্রস্তুত: পরামর্শমূলক চেকলিস্ট — আইনি/করের চূড়ান্ত সিদ্ধান্তের জন্য যোগ্য কর পরামর্শকের শরণাপন্ন হোন।*
